# 🎂 Birthday Universe

A personalized interactive birthday website made with HTML, CSS and JavaScript.

## ✨ Features

- Cinematic birthday homepage
- Personalized birthday messages
- Memory timeline
- Interactive memory gallery
- Bestie quiz
- Memory matching game
- Cake catching mini-game
- Interactive party planning form
- Background music
- Responsive mobile design
- Animated UI
- Vercel-ready static website

## 🚀 Run Locally

Open the project in VS Code.

Install the Live Server extension.

Right-click:

index.html

and select:

Open with Live Server

The website will open in your browser.

## 🌐 Deployment

This project is a static website and can be deployed using Vercel.

Recommended workflow:

1. Create a GitHub repository.
2. Push this project.
3. Import the repository into Vercel.
4. Deploy.

No backend or database is required.

## ❤️ Customization

Replace:

[HER NAME]

with the birthday person's name.

Replace the images inside:

assets/images/

with your own photos.

Replace:

assets/music/birthday-song.mp3

with the desired birthday song.

Update the memories and messages in the HTML files.
